## About Me

I am a Python Backend Developer focused on building
reliable, maintainable, and scalable applications.

My technical focus includes backend development,
RESTful API design, asynchronous programming,
database management, and software architecture.

I develop backend services using Django, FastAPI,
and Flask, work with relational databases and Redis,
and build Telegram bots and automation solutions.

I apply SOLID principles, object-oriented programming,
design patterns, and Clean Architecture to create
structured and maintainable code.

I also focus on application security, automated testing,
logging, containerization, CI/CD, and application
deployment in Linux environments.
